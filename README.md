# Weather Data Analyzer 🌦️

A Python data analysis project that fetches one year of weather data for Mangalagiri, Andhra Pradesh using the Open-Meteo REST API, cleans it with Pandas, and visualizes trends with Matplotlib and Seaborn.

## Features
- Fetches daily weather data (2025) using the Open-Meteo Archive API (no API key needed)
- Data cleaning: date conversion, missing value and duplicate checks
- Analysis: hottest/coldest day, rainiest day, monthly summary
- Visualizations: temperature trend, monthly rainfall, temperature heatmap

## Tech Stack
Python, Requests, Pandas, Matplotlib, Seaborn, Google Colab
